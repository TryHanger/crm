## Numbered Findings List

### [01] R-02 — Copywriting (Em Dash Ban)
- **Tier / Priority:** Hard Gate — **HIGH**
- **Location:** `apps/booking-web/src/components/ConfirmationScreen.tsx` (L66), `apps/platform-console/index.html` (L6), `apps/business-crm/src/modules/calendar/CalendarModule.tsx` (L1419), `apps/business-crm/src/modules/online-booking/OnlineBookingModule.tsx` (L399), `apps/platform-console/src/modules/companies/CompaniesModule.tsx` (L1196-1198)
- **Reason:** Forbidden em dash character (`—`) used in calendar summary, HTML titles, and UI text labels instead of clean punctuation (hyphen `-`, colon `:`, or parentheses).

### [02] R-25 — Color Contrast (WCAG AA)
- **Tier / Priority:** Hard Gate — **HIGH**
- **Location:** `apps/business-crm/src/modules/customers/CustomersModule.tsx` (L368, L421), `apps/platform-console/src/modules/companies/CompaniesModule.tsx` (L626, L796, L904, L1553), `apps/platform-console/src/layouts/PlatformLayout.tsx` (L165, L460)
- **Reason:** Text color `#94A3B8` (Slate-400) on light backgrounds (`#FFFFFF` and `#F8FAFC`) yields a 2.56:1 contrast ratio, failing the 4.5:1 minimum WCAG AA threshold for readable text.

### [03] R-32 — Keyboard Accessibility (Focus Outlines)
- **Tier / Priority:** Hard Gate — **HIGH**
- **Location:** `apps/booking-web/src/components/ConfirmationStep.tsx`, `apps/business-crm/src/modules/auth/LoginPage.tsx`, `apps/business-crm/src/modules/settings/SettingsModule.tsx`, `apps/platform-console/src/modules/auth/PlatformLoginPage.tsx`, `apps/platform-console/src/modules/companies/CompaniesModule.tsx` (27 occurrences)
- **Reason:** Form inputs and buttons use `outline: 'none'` without providing a visible custom `:focus-visible` indicator, blocking keyboard-only navigation.

### [04] R-39 — Accessible Semantics & Interaction Affordances
- **Tier / Priority:** Hard Gate — **HIGH**
- **Location:** `apps/business-crm/src/modules/calendar/CalendarModule.tsx` (L862, L922), `apps/business-crm/src/modules/services/ServicesModule.tsx` (L186), `apps/platform-console/src/layouts/PlatformLayout.tsx` (L738)
- **Reason:** Interactive calendar bookings and service rows use clickable `<div>` elements with `onClick` without semantic `<button>`, `role="button"`, or keyboard `onKeyDown` handlers.

### [05] R-17 & R-38 — Real Content vs Fabricated Placeholders
- **Tier / Priority:** Hard Gate — **HIGH**
- **Location:** `apps/booking-web/src/components/Header.tsx` (L39), `apps/platform-console/src/modules/companies/CompaniesModule.tsx` (L1553)
- **Reason:** Fallback phone number `+7 (701) 555-01-23` and sample domain `{t.slug}.book.example.kz` are hardcoded as simulated real data instead of displaying real tenant parameters or an honest placeholder.

### [06] R-04 — Raw Emoji Navigation Glyphs
- **Tier / Priority:** Purpose-Gate — **MEDIUM**
- **Location:** `apps/business-crm/src/layouts/CrmLayout.tsx` (L44-52), `apps/platform-console/src/layouts/PlatformLayout.tsx` (L39-61)
- **Reason:** Navigation menus use raw unicode emojis (`📅`, `👥`, `✂️`, `🏷️`, `🌐`, `📊`, `⚙️`) without `aria-hidden="true"`, causing screen readers to verbalize emoji names instead of section titles.

### [07] R-39 — Missing Global Interactive Cursor Rules
- **Tier / Priority:** Purpose-Gate — **MEDIUM**
- **Location:** `apps/business-crm/src/index.css` (missing), `apps/platform-console/src/index.css` (missing)
- **Reason:** Business CRM and Platform Console lack a shared base stylesheet ensuring `button, [role="button"], select { cursor: pointer; }` and disabled states show `cursor: not-allowed`.

### [08] R-11 — Inline Border Radius Fragmentation
- **Tier / Priority:** Quality Locks — **LOW**
- **Location:** All 3 frontend apps (`apps/booking-web`, `apps/business-crm`, `apps/platform-console`)
- **Reason:** Border radius values are scattered across inline styles (6px, 8px, 10px, 12px, 14px, 16px, 9999px) without a consistent design token hierarchy.

### [09] R-31 & antislop-code — Redundant AI Narrative Comments
- **Tier / Priority:** Quality Locks — **LOW**
- **Location:** `apps/booking-web/src/App.tsx` (L40, L57, L85, L94, L312, L591), `apps/booking-web/src/types.ts` (L31, L36)
- **Reason:** Single-line comments restate the obvious variable name or JSX section (`// Customer Form`, `// UI state`, `// Handlers`) without providing architectural value.
