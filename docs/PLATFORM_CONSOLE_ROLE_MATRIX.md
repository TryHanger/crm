# Platform Console Role-Based Access Control (RBAC) Matrix

> Официальная матрица ролей и разграничения полномочий персонала SaaS-платформы (`apps/platform-console`).
> Реализует принцип наименьших привилегий (Least Privilege) и строгую изоляцию платформы от клиентских CRM.

---

## 1. Роли персонала платформы

| Роль платформы | Назначение | Ключевые права | Запрещенные операции |
| :--- | :--- | :--- | :--- |
| **`platform_owner`** | Владелец платформы / Главный администратор | Полный доступ ко всем модулям платформы: онбординг, тарифы, приостановка/восстановление тенантов, управление персоналом платформы, аудит. | Прямой доступ к клиентским базам CRM без подтвержденного сеанса поддержки. |
| **`finance`** | Финансовый менеджер / Биллинг | Просмотр компаний, управление начислениями (`charges`), регистрация ручных оплат, подтверждение платежей, журнал аудита. | Приостановка/восстановление компаний, изменение тарифов, доступ к поддержке и техническим настройкам. |
| **`support`** | Инженер службы технической поддержки | Создание тенантов, диагностика компаний, переписка по тикетам, добавление временных исключений по фичам, запрос временного 30-минутного доступа к CRM (только с одобрения владельца тенанта). | Проведение оплат, смена тарифов компании, удаление/приостановка компаний, управление сотрудниками платформы. |
| **`viewer`** | Аудитор / Наблюдатель (Read-only) | Просмотр реестра компаний, тарифов, модулей и общих агрегированных показателей без права изменения данных. | Любые модифицирующие операции (`POST`, `PUT`, `PATCH`, `DELETE`). |

## 3. Правило взаимной изоляции сессий (Session Boundary Enforcement)

1. **Платформенный токен не дает прав в CRM:**
   - JWT токен, выданный сотруднику платформы (`platform_role != null`), отвергается эндпоинтами клиентских CRM (`/api/v1/business/*`) со статусом `403 Forbidden: Operation requires tenant membership`.
2. **CRM токен не дает прав в Platform Console:**
   - JWT токен сотрудника компании (владельца, администратора, мастера) не содержит активной записи в таблице `platform_staff`. Все запросы к `/api/v1/platform/*` отвергаются со статусом `403 Forbidden: User does not have platform management staff permissions`.
3. **Временный доступ инженера поддержки:**
   - Создает запись `SupportAccessSession` со строгим лимитом 30 минут.
   - Действует **только** для запрошенного `tenant_id`. Попытка доступа к любому другому тенанту блокируется с HTTP 403.
   - Каждое действие в сессии логируется в `PlatformAuditEvent`.
