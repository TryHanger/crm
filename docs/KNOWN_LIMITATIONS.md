## 2. Отложенный P1 Backlog (Production Gate)

1. **Time-first preview availability**:
   - В текущей реализации первичный выбор времени без заранее выбранных услуг показывает доступные интервалы филиала. При последующем выборе длительной комплексной услуги мастер проверяется на непрерывный слот. Если выбранное время недоступно, пользователю предлагается явный выбор альтернативных слотов.
2. **Quote storage growth & Rate Limiting**:
   - Таблица `booking_quotes` автоматически очищает просроченные записи (старше 1 часа) при генерации новых записей. Для промышленного развертывания (Production) рекомендуется настроить фоновый pg_cron / Celery task и строгий IP-based Rate Limiter на публичные эндпоинты `/api/v1/public/*`.
3. **Реальная доставка приглашений и уведомлений**:
   - Подключение внешнего SMTP/SMS провайдера для физической отправки писем со ссылками активации и напоминаниями о визите.
4. **Безопасная ротация секретов и резервное копирование**:
   - Внедрение HashiCorp Vault / AWS Secrets Manager для ротации `JWT_SECRET_KEY` и автоматического шифрованного `pg_dump` в S3/GCS.
5. **Docker Build в CI**:
   - Текущий рабочий процесс GitHub Actions проверяет PostgreSQL 17, миграции Alembic, 29 тестов Pytest, сборку TypeScript/Vite и E2E тесты Playwright. Сборка production Docker-образа вынесена в отдельный релизный пайплайн сборки образов (`release.yml`).
