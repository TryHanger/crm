## 2. Реализованные Backend API эндпоинты

Все клиентские операции подключены к реальным эндпоинтам `apps/api/app/api/v1/business/routes.py` с проверкой сессии, `crm_memberships`, роли и контекста организации:

1. **Клиенты (`/customers`)**:
   - `GET /customers` — поиск по имени и номеру телефона
   - `GET /customers/{id}` — полная карточка с историей бронирований и заметками
   - `POST /customers` — создание нового клиента
   - `PATCH /customers/{id}` — обновление контактов и предпочтений
   - `POST /customers/{id}/notes` — добавление внутренней приватной заметки мастера
2. **Сотрудники и графики (`/staff`)**:
   - `GET /staff` — список сотрудников с текущим статусом
   - `GET /staff/{id}` — детальный профиль
   - `POST /staff` — добавление нового мастера
   - `GET /staff/{id}/schedule` и `PUT /staff/{id}/schedule` — чтение и атомарное сохранение недельного графика смен (Пн-Вс)
   - `PUT /staff/{id}/services` — установка индивидуальных цен и длительностей мастера
3. **Каталог услуг (`/services`)**:
   - `GET /services` и `GET /service-categories` — каталог и категории
   - `POST /service-categories` и `PATCH /service-categories/{id}` — управление категориями
   - `POST /services` и `PATCH /services/{id}` — создание и редактирование услуги (цена, длительность, флаг онлайн-записи)
   - `DELETE /services/{id}` — безопасное архивирование (soft delete) без нарушения целостности FK в существующих бронях
4. **Онлайн-запись (`/booking-settings`, `/booking-theme`, `/booking-publication`)**:
   - `GET /booking-settings` и `PATCH /booking-settings` — правила бронирования (book-ahead, min-advance, cutoff)
   - `PATCH /booking-theme` — кастомизация корпоративных цветов и брендинга
   - `POST /booking-publication/publish` — переключение публикации и получение проверенного публичного URL
5. **Отчёты и аналитика (`/reports/overview`)**:
   - `GET /reports/overview?from_date=...&to_date=...&branch_id=...` — сводные метрики:
     - `total_bookings`, `completed_bookings`, `cancelled_bookings`, `no_show`
     - `planned_revenue_minor` — сумма активных броней в графике
     - `actual_revenue_minor` — фактическая выручка **только** по завершенным визитам
     - `new_customers_count` — число новых клиентов за период
     - `staff_stats` — выработка каждого специалиста (число визитов, факт-доход, % загрузки)
6. **Настройки бизнеса и команда (`/branches`, `/users`, `/invites`)**:
   - `GET/POST/PATCH /branches` — управление филиалами сети с контролем лимита по тарифу
   - `GET /users` — список пользователей тенанта со статусом и ролью
   - `POST /invites` — генерация защищенного токена приглашения для добавления сотрудника (без сброса существующего пароля)
