# Business CRM: новый дизайн по макету

Ветка `d2/crm-redesign`. Источник: макет «Business CRM — макет» (`index.html`, светлый bento: Onest, фиолетовый акцент, белые карточки, кнопки-«таблетки», тёмная тема).

## Что сделано

| Часть | Как |
|---|---|
| Дизайн-система | CSS макета перенесён целиком в `apps/business-crm/src/styles/crm.css` (токены, карточки, кнопки, таблицы, календарь, панели, мобильный таббар). В конце файла — дополнения для приложения: меню, экран входа, панель записи. |
| Оболочка | `layouts/CrmLayout.tsx` по макету: меню с группами «Работа / Бизнес / Система», выбор компании и филиала, переключатель темы (запоминается), мобильная шапка, таббар с кнопкой «+» и лист «Ещё». |
| Новый раздел «Обзор» | `modules/overview/OverviewModule.tsx` на реальных данных API: лента расписания на сегодня по мастерам (смены, записи, линия «сейчас»), следующая запись, загрузка, ближайшие записи, записи за неделю, свободные окна. |
| Все остальные экраны | Логика, вызовы API и `data-testid` не тронуты. Инлайн-цвета Tailwind (`#0F172A`, `#2563EB`, …) автоматически заменены на токены макета (`var(--fg)`, `var(--brand)`, …), скругления подняты до значений макета. Поэтому экраны работают и в тёмной теме. |
| Календарь | События окрашены по статусам макета. «В работе» — тёмная карточка, отмена — серая и зачёркнутая. Карточка записи открывается боковой панелью справа (на телефоне — листом снизу). |
| Вход и активация | Экраны `LoginPage`, `AcceptInvitePage` в стиле макета. |
| Иконки | Набор иконок макета — `ui/Icon.tsx`. Форматтеры и подписи статусов — `ui/format.ts`. |

## Что из макета пока не включено (нет в бэкенде)

Ниша «Ресторан» и схема зала, бонусы, LTV и сегменты клиентов, фото «как в прошлый раз», Telegram, рассылка «свободные окна», демо-переключатель акцента. Разметка и стили для них уже есть в `crm.css`, включаются вместе с функциями в API.

## Совместимость с e2e

Сохранены все `data-testid`, один `<header>` с названием компании, один `<nav>` (мобильный таббар — `div`), заголовки разделов в `h1`, кнопка «Выйти» в `.crm-desktop-sidebar`. Пункт меню «Услуги» назван так, чтобы не совпадать с вкладкой «Услуги и цены» в карточке сотрудника.

## Найдено попутно (логика фронта, не дизайн)

- Карточка отменённой записи показывает «Долг» и кнопку «Принять оплату». Оплата по отменённому визиту невозможна: API ответит 409.
