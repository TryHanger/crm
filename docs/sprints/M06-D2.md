# M06 · D2 · Три сценария клиентской записи: release note

Ветка: `d2/m06-booking-contract` (от `d2/m05-finance-ledger`).

## Что сделано

| Задача | Результат |
|---|---|
| M06-D2-01 контракт availability/quote/booking без правил в UI | Контракт описан в `docs/booking/PUBLIC_BOOKING_CONTRACT.md`. Новый `POST /public/availability/time-first` показывает время, когда свободен хотя бы один мастер. Каждый мастер проверяется своей самой короткой услугой через тот же движок, quote не создаются. В `POST /availability/search` добавлено `at_utc`: точное время даёт quote или до 6 ближайших подходящих стартов (`exact_match`, `alternatives`). Валидация запроса: режим мастера, `specific` требует мастера, без повторов услуг, порядок дат, пояс в `at_utc`, чужой филиал → 404. Валюта слота берётся из снимка позиций, а не константой `KZT`. В `@crm/api-client` добавлены `searchTimeFirst`, типы `TimeFirst*`, поля `at_utc` / `exact_match` / `alternatives`. |
| M06-D2-02 contract-тесты | `test_booking_contract.py` (5 тестов): две услуги одного мастера с его ценой и длительностью (сумма, сетка, снимок цен по позициям), `409 QUOTE_CHANGED` после смены цены, цены мастера в каталоге = цене слота, порядок «любого мастера» по времени и цене, time-first до настоящей брони, валидация. |
| M06-D2-03 выпуск | `smoke_booking_flows.py`: три сценария на живом стеке, каждый заканчивается записью со ссылкой управления. Добавлен в `dev_stack --smoke` и CI. Фабрика тестовых компаний вынесена в `apps/api/tests/company_factory.py`. |

## Найдено

- **STOP-критерий M06 сейчас выполняется в Booking Web.** В сценарии «сначала время» UI ищет слоты для `services[0]` (первая услуга каталога), а если клиент так и не выбрал услугу, создаёт бронь по ней же. Время подбиралось под чужую длительность. Серверная часть исправления готова, **перевод UI на `searchTimeFirst` + `at_utc` — задача D1 (M06-D1)**.
- Поиск с несуществующим или чужим `branch_id` раньше молча работал с поясом Almaty и возвращал пустой список. Теперь 404.
- `staff_mode` принимал любую строку, `specific` работал без мастера (фактически как `any`), повтор услуги удваивал цену и длительность. Теперь 422.

## Ограничения

- Поиск сохраняет quote для каждого слота (было и раньше). `time-first` и превью `at_utc` quote не пишут, но обычный поиск по-прежнему пишет. Нагрузка на `booking_quotes` — тема M07.
- Time-first показывает время по самой короткой услуге мастера. Подходят ли выбранные услуги, решает шаг `at_utc`, это заложено в контракт.
- `packages/api-contracts/openapi.json` не перегенерирован (в репозитории нет скрипта генерации). Источник правды — FastAPI `/openapi.json`.
