## Приёмка M03

- Системная ссылка открывает только свою компанию: `barberhouse…` даёт Barber House, `moderncut…` даёт Modern Cut, неизвестный slug даёт 404 `SITE_NOT_FOUND`.
- Пауза публикации из CRM: сайт отвечает 404 `SITE_NOT_PUBLISHED`, новая запись отклоняется, другая компания продолжает работать. После снятия паузы всё восстанавливается.
- STOP-критерий «неизвестный Host обслуживается как существующая компания» не выполняется: чужой домен режется ещё до поиска компании, и nginx, и API.

## Изменения поведения

- Staging/production: API на чужом хосте отвечает 404. Внешние вызовы API теперь должны идти через `api.<root>` или домен своего приложения.
- В тестах `test_pilot_security_readiness`: IP-allowlist платформы проверяется на домене консоли, код для чужого хоста теперь `HOST_NOT_ALLOWED`.
- Новые переменные: `API_DOMAIN` (по умолчанию `api.example.kz`), `STRICT_HOST_ROUTING`, `PROXY_HTTP_PORT` для staging compose (на Windows порт 80 часто занят http.sys).
- `normalize_hostname` убирает завершающую точку (`host.` = `host`).

## Доказательства (локально, 18.11.2026)

- `pytest apps/api/tests`: **97 passed** (68 + 29 новых).
- Staging в Docker (`PROXY_HTTP_PORT=8080 python scripts/verify_staging_deployment.py --teardown`): **exit 0**.
  - TLS SNI: позитивные и негативные пробы, неизвестный хост получает 404, все 3 SPA отдаются по HTTPS.
  - Матрица маршрутизации через nginx (9 проб): с домена записи нельзя попасть в auth, platform и business; CRM не отдаёт platform и public; консоль не отдаёт business; `api.*` отдаёт auth и не отдаёт public; неизвестный салон получает 404.
  - Сквозной сценарий из 12 шагов по HTTPS: компания и приглашение (M02), публикация, запись, CRM видит визит, пауза публикации даёт 404, изоляция A/B.
- Первый прогон staging поймал реальную ошибку: регулярка с `{0,61}` в `server_name` без кавычек ломала nginx. Исправлено, `nginx -t` проходит.

## Ограничения и что дальше

- Собственные домены салонов (E17) нужно будет разрешить в `host_policy`: проверенный custom-домен из `tenant_domains` должен получать `public`. Сейчас custom-доменов создавать негде, в демо-данных есть только `*.localhost`.
- QR, ссылка и переключатель публикации в CRM относятся к зоне D1 (M03-D1).
- Боевых DNS и сертификата пока нет: это задача M16.
